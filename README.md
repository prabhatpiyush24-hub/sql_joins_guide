# SQL Joins Guide

An interactive presentation that teaches SQL JOIN types through theory, storytelling, and real SQL examples.

## 📚 What's Covered

This guide covers all essential SQL JOIN types:

- **INNER JOIN** - Returns rows that have matching values in both tables
- **LEFT JOIN** - Returns all rows from the left table, and matched rows from the right table
- **RIGHT JOIN** - Returns all rows from the right table, and matched rows from the left table
- **FULL OUTER JOIN** - Returns all rows when there is a match in either table
- **CROSS JOIN** - Returns the Cartesian product of both tables
- **SELF JOIN** - Joins a table with itself

## 📖 Learning Path

The presentation follows a logical progression:
1. What is a SQL JOIN?
2. INNER JOIN (the most common type)
3. LEFT JOIN (preserves all left table rows)
4. RIGHT JOIN (preserves all right table rows)
5. FULL OUTER JOIN (combines left and right)
6. CROSS JOIN (all combinations)
7. SELF JOIN (table joins itself)
8. Quick Reference summary
9. Hosting instructions
10. Closing
